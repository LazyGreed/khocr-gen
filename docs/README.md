# Documentation

`src/khocr_gen/` and the tests define current behavior. These guides help you use and change the
project.

## In-repository references

- [CLI reference](CLI_REFERENCE.md) — commands and flags.
- [Configuration](CONFIG.md) — YAML keys and precedence.
- [Augmentation](AUGMENTATION.md) — augmentation methods and intensity ranges.
- [Rust acceleration](RUST_ACCELERATION.md) — the native extension and Python fallback.

The [wiki source](../wiki/README.md) covers installation, getting started, fonts, corpus handling,
variable line height, output formats, and troubleshooting. Publish changes from `wiki/` with
[`scripts/publish_wiki.sh`](../scripts/publish_wiki.sh).

[Archived design notes](archive/README.md) are historical proposals, not current behavior references.
